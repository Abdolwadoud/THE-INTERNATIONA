# THE-INTERNATIONAL — clean starter

This is a starter, not yet a complete school platform. Lessons are samples and progress is stored on the device only.

## Build Android APK with GitHub Actions
1. Upload the files and `.github/workflows/android-apk.yml` to a GitHub repository.
2. Open Actions and run **Build Android APK**.
3. Download the `THE-INTERNATIONAL-debug-apk` artifact and extract `app-debug.apk`.

Minimum Android version is set to Android 11 (API 30) by the workflow. This does not guarantee every device will install it; test the APK on real devices.
